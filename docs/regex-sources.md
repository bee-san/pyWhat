# Where regexes come from

Most of pyWhat's regexes are written from the documentation of the format they identify. When a
regex is adapted from another project, it is listed here. Only projects under MIT, BSD,
Apache-2.0, CC0 or a public-domain dedication can be sources, as the regexes ship in the
Python package and the Rust crate (docs/adding-regexes.md).

| Regexes | Project | URL | Licence |
|---|---|---|---|
| bug bounty regexes (README, "Thanks") | Dora | https://github.com/sdushantha/dora | MIT |
| patterns of gf (README, "Thanks") | gf (tomnomnom) | https://github.com/tomnomnom/gf | MIT |
| cron schedules, browser user agents, ISO 8601 timestamps, UK postcodes, regex101 permalinks (README, "Thanks") | the regex101 community library | https://regex101.com/library | not stated by regex101 (open question for the owner: record each entry's author and licence, or rewrite these from the formats' documentation) |
